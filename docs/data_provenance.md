# Data provenance

- `sample_geometry_ascii.stl`: created for this prototype as a four-facet tetrahedron. Coordinates are dimensionless/arbitrary because STL does not carry units. No external source or license is involved.
- `sample_temperature_synthetic.csv`: generated by `tools/generate_reference.py` from the analytical rod temperature curve at x=0..1 m. Explicitly synthetic; not exported by ANSYS.
- `fea_N40_analytical_reference.csv`, `fea_convergence_reference.csv`, and `nn_loss_reference.csv`: deterministic mathematical references generated from the task's equations. They are not evidence that the C++ executable ran.
